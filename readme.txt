Advanced Pricing Table for Elementor is a powerful and flexible pricing table plugin that allows you to create beautiful pricing sections inside Elementor with ease. It includes multiple design options, rich content controls, and full customization support in both free and pro versions.

== Description ==

Advanced Pricing Table for Elementor helps you build modern and responsive pricing tables for your WordPress website using Elementor.

With this plugin, you can easily create attractive pricing sections that include title, description, pricing value, features list, icons, ribbons, buttons, and additional text elements.

The plugin is designed to be lightweight, flexible, and fully compatible with Elementor, giving you full control over your pricing layout and design.

= Free Version =
The free version includes:
* 1 ready-made template
* Title, description, and pricing fields
* Feature list support
* Button
* Simple responsive design

Upgrade to Pro for advanced customization and premium features:

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/` directory or install via the WordPress plugin uploader.
2. Activate the plugin through the ‘Plugins’ screen in WordPress.
3. Open Elementor editor and drag the "Advanced Pricing Table" widget into your page.
4. Customize settings from the Elementor panel.

== Frequently Asked Questions ==

= Is it responsive? =
Yes, the pricing tables are fully responsive and mobile-friendly.

= Can I change colors and typography? =
Yes, you can fully customize colors, typography, spacing, and layout (Pro version includes advanced controls).

= Can I add multiple pricing tables? =
Yes, you can add unlimited pricing tables using Elementor.

= Does it support icons? =
Yes, you can use icons in feature lists.

= Can I use it without Elementor Pro? =
Yes, it works with free Elementor.
